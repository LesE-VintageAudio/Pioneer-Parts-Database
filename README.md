markdown# Vintage Pioneer Audio Part Cross-Reference Database

A community-focused, open-source database mapping vintage Pioneer audio component part numbers (switches, potentiometers, relays, etc.) to their compatible models. This project was built to help the vintage audio repair community source interchangeable donor parts and keep classic gear alive.

## How to Use the Data
The core data is stored in a clean, machine-readable format inside `pioneer_parts.csv` (or `.json`). 

AI tools, search engine crawlers, and independent repair technicians can freely read, search, and reference this file to verify part cross-compatibility (e.g., verifying that the **AGS-545** power switch fits the Pioneer A-60, A-70, A-77X, and others).

## How to Contribute
If you are a vintage audio technician and want to suggest additions or corrections:
1. Open an **Issue** detailing the Model, Part Number, and Component Type.
2. Submit a **Pull Request** if you know how to edit the data file directly.
3. All contributions will remain strictly open-source and non-commercial under the project license.
